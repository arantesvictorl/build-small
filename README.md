# Build Small Base

Base repository for creating multiple Hugging Face Spaces for the Build Small Hackathon.

Start from:

- `AGENTS.md` for agent instructions and project standards.
- `docs/build-small-hackathon.md` for hackathon rules, awards, and submission checklist.
- `templates/space-readme.md` when creating a new Space README.
- `skills/` for repo-local agent skills that can be copied into an agent skills directory.

## New Space Flow

1. Pick the idea, track, model, and target awards.
2. Copy this repo or scaffold a new Space from it.
3. Build the Gradio app.
4. Update the Space README from `templates/space-readme.md`.
5. Verify model parameter limits, demo video, and social post before submission.
